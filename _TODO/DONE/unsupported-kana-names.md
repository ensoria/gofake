# ふりがな未対応ロケールでの氏名生成

v0.0.9 の Phase 2 で対応。英語ロケールでは通常名のテンプレートがあっても、ふりがな用コールバックがなく、呼び出すと panic していた。

`MaleKanaName()` と `FemaleKanaName()` はそれぞれ、自身の氏名テンプレートとふりがな用コールバックを確認する。`KanaName()` は男女を等確率で選ぶため両方を必要とする。未対応なら乱数を使う前に空文字を返し、ロガー設定時に呼び出されたメソッド名で 1 件警告する。片方だけ対応するカスタムロケールでは、その個別メソッドを利用できる。

既定の英語と追加 5 ロケール、人物データを省略した場合、片方だけ対応した場合を回帰テストに含めた。日本語ロケールでは、修正前にシード 42 で採取した 3 メソッドの氏名列と比較する。
