# Migrating from gofake v0.0.8 to v0.0.9

[日本語](v0.0.8-to-v0.0.9.ja.md) · [Changelog](../../CHANGELOG.md)

## Update the toolchain and dependency

The minimum Go version rises from 1.24.2 to **1.26.4**. Update your local toolchain, CI configuration and Docker build image. Your application's `go.mod` must declare Go 1.26.4 or later. From its module root, run the following after the v0.0.9 tag is available.

```sh
go version
go get github.com/ensoria/gofake@v0.0.9
```

## Replace field access with method calls

In v0.0.8:

```go
n := f.Rand.Num.IntBt(1, 10)
p := f.Person
name := p.Name()
```

In v0.0.9:

```go
n := f.Num().IntBt(1, 10)
p := f.Person()
name := p.Name()
```

| v0.0.8 | v0.0.9 |
| --- | --- |
| `f.Rand.Bool` | `f.Bool()` |
| `f.Rand.Num` | `f.Num()` |
| `f.Rand.Str` | `f.Str()` |
| `f.Rand.Time` | `f.Time()` |
| `f.Rand.Slice` | `f.Slice()` |
| `f.Rand.Map` | `f.Map()` |
| `f.Person` | `f.Person()` |
| `f.Color` | `f.Color()` |
| `f.Address` | `f.Address()` |
| `f.Barcode` | `f.Barcode()` |
| `f.Company` | `f.Company()` |
| `f.File` | `f.File()` |
| `f.Image` | `f.Image()` |

A constructor initializes all 19 generators. Each accessor returns the same generator pointer on repeated calls. Review assignments and callbacks as well as chained calls. For example, `var x any = f.Person` still compiles, but stores a method with type `func() *person.Person`. Use `f.Person()` to store the generator.

## Update code that stores or constructs Faker values

- Replace keyed `faker.Faker{…}` literals and generator field assignments with a constructor. Use `faker.CreateWithSeed(seed)` or `faker.CreateWithLocaleAndSeed(locale, seed)` when you need reproducible output. A copy of a constructed Faker shares its generator pointers. Construct a second instance for an independent stream.
- For a custom `*rand.Rand` from `math/rand`, call `r := core.NewRand(source)`. Its fields remain available, for example `r.Num.IntBt(1, 10)`. Pass the same `r` to constructors such as `person.New(r, locale)` to share its stream. Import `core` and `generator/person` under `github.com/ensoria/gofake/pkg/faker/`.
- The accessors have pointer receivers. Pass `*faker.Faker` to interfaces that require them. For a `map[string]faker.Faker` element or a function result of type `faker.Faker`, assign the value to a local variable before calling a method, or store pointers. An encli seeder with `Seed(faker.Faker)` can keep its signature and call `f.Person().Name()` on its parameter.
- Code that reflects on exported fields or serializes a Faker should define a struct containing the generated values it needs.

## Handle unavailable data

- `Company().EIN()` generates a synthetic U.S. EIN when the locale supplies prefixes. Otherwise it returns `""` and emits one warning if a logger is configured. Replace assertions expecting a value such as `-1234567`. The call now consumes no randomness in that case, so review any seeded golden data generated **after** it.
- `Person().MaleKanaName()`, `FemaleKanaName()` and `KanaName()` return `""` for an unsupported request and emit one warning when logging is enabled. Previously a missing kana callback could panic. If a custom locale supports only one variant, call its gender-specific method. `KanaName()` requires both.

## Verify the application and encli

```sh
go mod tidy
go test ./...
```

If you use Ensoria, install an encli binary that supports the new locale once it is released, and update gofake in the project where you run `encli seed`. The command builds its runner using that project's dependencies. Updating the encli module can also raise the selected gofake version. Check both with `go list -m github.com/ensoria/gofake github.com/ensoria/encli`, then exercise your seeders and review seeded fixtures using your application's call order.
